# 🎃 Halloween Special 👻

Een interactieve Halloween-webpagina gemaakt met **HTML, CSS en JavaScript**.

De website heeft verschillende Halloween-effecten, animaties en interactieve functies.

## 👻 Functionaliteiten

- 🌫️ Bewegende mist over de Halloween-afbeelding
- 🔥 Vuureffect bij de Halloween-knop
- 🌑 Dark mode
- 💚💛 Groen-gele gradient achtergrond
- 👻 Interactieve "Summon the Ghosts"-knop
- 🔄 Afbeelding draaien
- 🎨 Kleuren veranderen
- 🎃 Automatisch berekenen hoeveel dagen het nog is tot Halloween
- 🕸️ Halloween emoji's en decoraties
- ✨ Glow- en hover-effecten
- 💀 Speciale Halloween-fonts

## 🛠️ Gebruikte technieken

- HTML5
- CSS3
- JavaScript

### CSS

Voor de visuele effecten worden onder andere gebruikt:

- CSS Grid
- Linear gradients
- `@keyframes` animaties
- `box-shadow`
- `text-shadow`
- `filter`
- `transform`
- `transition`
- `::before` en `::after`
- Absolute en relative positioning

### JavaScript

JavaScript wordt gebruikt voor de interactieve onderdelen van de website, zoals:

- Dark mode aan- en uitzetten
- Tekst veranderen
- CSS classes toggelen
- Afbeelding draaien
- Kleuren veranderen
- Het aantal dagen tot Halloween berekenen

## 🎨 Design

De website heeft een Halloween-thema met:

- 🎃 Oranje
- 💚 Groen
- 💛 Geel
- 💜 Paars
- 🖤 Donkere kleuren

Daarnaast worden speciale Halloween-fonts zoals **Creepster** en **Nosifer** gebruikt.

## 🎃 Halloween Special — Interactieve Halloween-website

Halloween Special is de eerste pagina van ons Halloween-project.

De website is gebouwd met HTML, CSS en JavaScript en heeft
een mysterieuze Halloween-sfeer met interactieve knoppen,
animaties, geluidseffecten en verschillende visuele effecten.

### Bestanden
- `index.html` — structuur en inhoud van de hoofdpagina
- `style.css` — vormgeving, animaties en visuele effecten
- `script.js` — interactieve JavaScript-functionaliteiten
- `images/` — afbeeldingen voor de Halloween-website
- `music/spooky-music.mp3` — achtergrondmuziek

### Functionaliteiten

#### 🌙 Dark Mode
- Schakelen tussen de normale weergave en Dark Mode
- Achtergrondkleur en tekstkleur aanpassen
- Visuele overgang tussen beide weergaven

#### 🎵 Halloween-muziek
- Griezelige achtergrondmuziek afspelen
- Muziek pauzeren en opnieuw starten
- Bediening via een interactieve knop

#### 🌫️ Bewegende mist
- Een mistlaag over de Halloween-afbeelding
- Bewegende mist met CSS-animaties
- Transparantie en kleurovergangen voor een mysterieus effect

#### 👻 Interactieve geesten
- Knop "Summon the ghosts"
- Tekst dynamisch veranderen met JavaScript
- CSS-klassen toevoegen en verwijderen voor visuele effecten

#### 🎃 Halloween-afteller
- Berekenen hoeveel dagen het nog duurt tot Halloween
- Automatisch rekening houden met het volgende jaar
- Het resultaat dynamisch weergeven op de pagina

### CSS-effecten en vormgeving
In `style.css` zijn verschillende effecten toegepast:

- Halloween-kleuren en achtergrondverlopen
- Speciale lettertypen, waaronder Creepster en Nosifer
- Oranje licht- en gloeieffecten rond knoppen
- Hover-effecten en vloeiende overgangen

- Afbeeldingseffecten en fade-in-animaties
- Decoratieve druipende elementen onder de titel

## 👻 Week 7 — Halloween Fetch API en UML Sequence Diagram

Voor de Week 7-opdracht is een aparte Halloween Fetch API-oefening
gemaakt met HTML en JavaScript.

De pagina haalt vijf berichten op uit een externe API en toont
deze dynamisch op de webpagina.

Daarnaast is een UML-sequencediagram gemaakt om de communicatie
tussen de gebruiker, JavaScript en de API inzichtelijk te maken.

### Bestanden
- `halloween-fetch.html` — structuur van de Fetch API-oefenpagina
- `halloween-fetch.js` — ophalen en verwerken van API-gegevens
- `halloween-fetch-sequence.drawio` — bewerkbaar UML-sequencediagram

### Functionaliteiten
- Vijf berichten ophalen via de Fetch API
- Gegevens ophalen van JSONPlaceholder
- Berichten laden met een knop
- Laadmelding tonen tijdens het ophalen
- Bestaande resultaten verwijderen vóór een nieuwe aanvraag
- Laadknop tijdelijk uitschakelen
- HTTP-response controleren met `response.ok`
- JSON-gegevens verwerken met `response.json()`
- Berichten dynamisch weergeven met JavaScript
- Voor ieder bericht een `<article>` maken
- Titels en beschrijvingen toevoegen
- Het aantal opgehaalde berichten tonen
- Een melding tonen bij een lege berichtenlijst
- Foutmeldingen tonen bij mislukte API-aanvragen
- Laadknop opnieuw inschakelen met `finally`

### Gebruikte JavaScript-technieken
- Fetch API
- `async` en `await`
- `fetch()`
- `response.ok`
- `response.json()`
- `try`, `catch` en `finally`
- Arrays en objecten
- `forEach()`
- `createElement()`
- `textContent`
- `appendChild()`
- `addEventListener()`
- DOM-manipulatie
- Asynchrone JavaScript
- Foutafhandeling

### UML Sequence Diagram
Voor de Fetch API-oefening is een UML-sequencediagram gemaakt
in draw.io binnen Visual Studio Code.

Het diagram bevat drie deelnemers:
- Gebruiker
- Pagina / JavaScript
- API

De volgende onderdelen zijn weergegeven:
- Gebruiker klikt op de laadknop
- JavaScript toont een laadmelding
- Bestaande resultaten worden leeggemaakt
- De laadknop wordt tijdelijk uitgeschakeld
- JavaScript verstuurt een Fetch-verzoek naar de API
- De API stuurt een HTTP-response terug
- JavaScript verwerkt de JSON-gegevens
- Een `alt`-blok voor succes en fout
- Een tweede `alt`-blok voor gevonden berichten en een lege lijst
- Berichten of foutmeldingen worden weergegeven
- De laadknop wordt opnieuw ingeschakeld via `finally`

### Testen
De Fetch API-oefening is functioneel getest.

Onder andere de volgende situaties zijn gecontroleerd:
- Correct ophalen en weergeven van vijf berichten
- Twee keer op de laadknop klikken zonder dubbele berichten
- Lege API-response met `_limit=0`
- Foutafhandeling bij een ongeldige API-URL
- Herstellen van de oorspronkelijke API-URL
- Correct opnieuw laden van de berichten
- Console controleren op JavaScript-fouten

Na het testen is de oorspronkelijke API-URL hersteld:

`https://jsonplaceholder.typicode.com/posts?_limit=5`

### Status
De Fetch API-oefening werkt correct.

De functionele tests zijn geslaagd en het UML-sequencediagram
is afgerond.
